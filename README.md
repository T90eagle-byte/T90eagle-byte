# Информационная безопасность

Начинающий специалист в области информационной безопасности.

## Профессиональные интересы

- Сетевая и инфраструктурная безопасность
- Безопасность операционных систем
- Анализ сетевого трафика
- Мониторинг событий информационной безопасности
- Развёртывание и администрирование IT-инфраструктуры

## Проекты и исследования

| Проект | Описание |
|---|---|
| [Format Security Pattern](https://github.com/T90eagle-byte/format-security-pattern) | Микросервисный прототип контроля безопасности входных данных |
| [Security Research](https://github.com/T90eagle-byte/security-research) | Портфолио прикладных научных исследований |
| DNS Tunnel Detection | Исследование статистических методов обнаружения DNS-туннелирования (в разработке) |

## Технические компетенции

- Сетевые технологии: TCP/IP, VLAN, OSPF, IGMP, DNS, DHCP, SNMP, Syslog.
- Сетевое оборудование: Cisco, Eltex, MikroTik.
- Операционные системы: Linux, ALT Linux, Windows Server.
- Инфраструктура: Active Directory, VirtualBox, Docker.
- Информационная безопасность: анализ сетевого трафика, моделирование угроз, MITRE ATT&CK.

## Научная деятельность и сертификация

- Соавтор четырёх научных статей.
- Академия Eltex — «Основы сетевых технологий. Часть 1 (v.1.2)», 2026.
- Академия Eltex — «Основы сетевых технологий. Часть 2 (v.2)», 2026.
